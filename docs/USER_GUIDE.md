# Руководство пользователя TempNoteManager

TempNoteManager помогает быстро разобрать файлы, открытые в Notepad++: временные заметки, постоянные файлы и файлы, которые нужно разложить по хранилищам-категориям.

Главная идея: слева находится рабочий список файлов, справа открывается выбранный файл, а категории помогают физически разложить файлы по директориям.

## Перед началом

Рекомендуется закрыть Notepad++ перед операциями, которые меняют `session.xml` или физически перемещают файлы.

Это особенно важно для действий:

- `Порядок`
- `↶`
- `Сохранить как...`
- `Сделать временным`
- `Удалить`
- перемещение файла в категорию
- возврат файла из категории в общий список
- переименование файла

Если Notepad++ открыт, он может позже перезаписать `session.xml` своими текущими данными.

## Первый запуск

1. Запустите `TempNoteManager.exe`.
2. Нажмите `Настройки`.
3. Проверьте путь к `session.xml`.
4. Если путь не найден автоматически, нажмите `…` рядом с `session.xml` и выберите файл сессии Notepad++.
5. При необходимости выберите корневую папку категорий.
6. Нажмите `Сохранить`.
7. Нажмите `Обновить`, чтобы перечитать список файлов.

Обычно `session.xml` находится здесь:

```text
%APPDATA%\Notepad++\session.xml
```

По умолчанию корневая папка категорий создается в документах:

```text
%USERPROFILE%\Documents\TempNoteManager Categories
```

## Главный экран

В верхней части окна находится рабочая панель команд: обновление, настройки, отмена операции, удаление, переименование, перенос в категорию, блокировка, избранное, экспорт, AI-разметка и сохранение порядка.

Все редкие параметры вынесены в кнопку `Настройки`:

- путь к `session.xml` Notepad++;
- включение AI;
- автоматический расчет AI-описания;
- адрес API, модель и AI-ключ;
- режим корзины;
- корневая папка категорий.

Основная область состоит из двух частей:

- слева список файлов;
- справа панель полного просмотра выбранного файла.

Если закрыть правую панель кнопкой `×`, список снова занимает больше места.

## Режимы списка

Список можно смотреть в двух режимах:

- `Таблица`
- `Карточки`

В таблице доступны колонки:

- `Флаги`
- `Дубль`
- `Имя`
- `Тип`
- `Создан`
- `Изменен`
- `Размер`
- `Категория`
- `Тэги`
- `Путь`

Для длинных путей используйте горизонтальную прокрутку таблицы.

В карточках удобнее быстро просматривать краткий текст, описание, тэги и принадлежность к категории.

## Поиск и фильтр

Используйте строку поиска над списком, чтобы отфильтровать файлы по имени, пути, категории, тэгам или описанию.

Флажок `Только временные` оставляет в списке только временные файлы Notepad++.

Дополнительные фильтры:

- `Неразобранные` - показывает файлы без категории.
- `Дубликаты` - показывает файлы с одинаковым хэшем содержимого.
- `Избранные` - показывает файлы с флагом `★`.

## Предпросмотр и полный просмотр

Наведение на элемент списка запускает быстрый предпросмотр. Если AI включен, приложение показывает готовое описание из кэша. Если включен флажок автоматического описания, приложение может рассчитать его автоматически.

Если автоматическое описание выключено, новые AI-запросы не запускаются при наведении или открытии файла. Для ручного расчета используйте кнопку `AI описание` в правой панели.

Клик по файлу открывает справа полную панель просмотра. В ней видно:

- имя файла;
- полный путь;
- время создания;
- время изменения;
- AI-тэги;
- AI-описание;
- содержимое файла.

Файлы внутри категорий открываются так же: нажмите на файл в карточке категории, и он появится справа.

## Временные и постоянные файлы

TempNoteManager различает:

- временные файлы Notepad++;
- постоянные файлы на диске;
- файлы, лежащие в backup-хранилище Notepad++.

Временный файл можно сделать постоянным:

1. Выберите временный файл.
2. Нажмите `Сохранить как...` в правой панели.
3. Выберите путь сохранения.
4. Приложение скопирует содержимое и обновит `session.xml`.

После этого Notepad++ будет считать файл постоянным.

Постоянный файл можно сделать временным:

1. Выберите постоянный файл.
2. Нажмите `Сделать временным`.
3. Подтвердите действие.
4. Приложение создаст временную копию в backup-папке Notepad++ и обновит `session.xml`.

## Экспорт временных файлов

Кнопка `Экспорт` копирует все доступные временные файлы в выбранную папку.

Это не меняет `session.xml` и не делает файлы постоянными. Это быстрый способ сохранить копии временных заметок перед разбором.

## Сортировка и порядок вкладок

Файлы можно перемещать:

- перетаскивание мышью в таблице;
- перетаскивание мышью в карточках;
- кнопками `↑` и `↓` для выбранного элемента или выделенной пачки.

Можно выделить несколько файлов в таблице или карточках через `Shift`/`Ctrl`. Массовое выделение работает для удаления, переноса в категорию, `Блок`, `★` и `AI разметка`.

После перемещения порядок меняется локально в TempNoteManager.

Чтобы записать новый порядок обратно в Notepad++:

1. Закройте Notepad++.
2. Нажмите `Порядок`.
3. Подтвердите запись в `session.xml`.

## Удаление файлов

Кнопка `Удалить` удаляет выбранный файл или выбранную пачку из списка Notepad++ и перемещает файлы в корзину.

Режим корзины выбирается в `Настройках`:

- `Корзина Windows` - системная корзина Windows.
- `Пользовательская папка` - пользовательская папка-корзина.

Если выбран режим `Пользовательская папка`, укажите путь рядом с полем корзины или нажмите `…`.

Перед удалением приложение показывает подтверждение с количеством файлов, выбранной корзиной и примером списка.

Если файл уже отсутствует на диске, TempNoteManager предложит удалить только запись из `session.xml`.

## Отмена и журнал операций

Кнопка `↶` откатывает последнюю опасную операцию, если для нее есть снимок `session.xml` или обратимый путь файла.

Что откатывается хорошо:

- сохранение порядка вкладок;
- переименование;
- перенос в категорию;
- возврат из категории;
- удаление в пользовательскую папку-корзину.

Если файл был отправлен в системную корзину Windows, TempNoteManager восстановит `session.xml`, но сам файл нужно вернуть из корзины Windows вручную.

Журнал хранится здесь:

```text
%APPDATA%\TempNoteManager\operation-journal.json
%APPDATA%\TempNoteManager\session-backups
```

## Блокировка, избранное и дубликаты

Кнопка `Блок` ставит или снимает защитный флаг блокировки. Если удалить, переименовать или переместить заблокированный файл, приложение попросит снять блокировку и подтвердить действие.

Кнопка `★` ставит или снимает флаг избранного. Используйте его для важных заметок, которые нужно быстро найти через фильтр `Избранные`.

Дубликаты определяются по хэшу содержимого файла. Если несколько файлов имеют одинаковое содержимое, в колонке `Дубль` появится группа вроде `D1 x3`.

Флаги хранятся локально и привязаны к хэшу содержимого, поэтому обычно сохраняются после переименования или переноса файла.

## Переименование файлов

Файл можно переименовать из:

- верхней кнопки `Переим.`;
- строки таблицы;
- карточки;
- файла внутри категории;
- правой панели просмотра.

При переименовании приложение:

- физически переименовывает файл на диске;
- обновляет путь в `session.xml`;
- сохраняет связь с AI-кэшем, если содержимое файла не изменилось.

## Категории-хранилища

Категории - это реальные директории на диске. Они нужны, чтобы быстро разобрать файлы по смысловым папкам.

Чтобы создать категорию:

1. Нажмите `Настройки` и проверьте корневую папку категорий.
2. Нажмите `+` в блоке `Категории`.
3. Введите название.
4. Выберите цвет или нажмите `Авто по описанию`.
5. Заполните `Описание для AI`.
6. Нажмите `Создать`.

Описание помогает AI понять, какие файлы относятся к категории.

Пример описания:

```text
Черновики SQL-запросов, миграции, выборки, заметки по структуре баз данных.
```

## Цвета категорий

Цвет можно выбрать вручную из списка или ввести в формате:

```text
#RRGGBB
```

Кнопка `Авто по описанию` подбирает цвет по тексту описания категории. Это локальная эвристика, отдельный AI-запрос для цвета не нужен.

## Перемещение файлов в категории

Чтобы переместить файл в категорию:

1. Выберите один или несколько файлов.
2. Перетащите выделение на карточку категории или нажмите `В катег.`.
3. Подтвердите действие.

После подтверждения приложение:

- физически перемещает файл в директорию категории;
- обновляет путь в `session.xml`;
- обновляет список.

Чтобы вернуть файл из категории в общий список:

1. Перетащите файл из категории обратно в основной список.
2. Подтвердите действие.

Важно: при возврате из категории файл перемещается в общий корень категорий, а не в исходную папку, где он лежал до разбора.

## AI: подключение

AI-функции необязательны. Без AI приложение продолжает работать как менеджер файлов и сессии Notepad++.

Чтобы включить AI:

1. Нажмите `Настройки`.
2. Поставьте флажок `Включить AI`.
3. Укажите адрес API.
4. Укажите модель.
5. Введите AI-ключ.
6. Нажмите `Сохранить`.

Адрес API по умолчанию:

```text
https://api.openai.com/v1/chat/completions
```

Модель по умолчанию:

```text
gpt-4.1-mini
```

AI-ключ сохраняется в Windows Credential Manager:

```text
TempNoteManager.AI.ApiKey
```

В `settings.json` ключ не записывается.

Также поддерживаются переменные окружения:

```powershell
$env:TEMP_NOTE_AI_API_KEY = "..."
$env:OPENAI_API_KEY = "..."
$env:TEMP_NOTE_AI_ENDPOINT = "https://api.openai.com/v1/chat/completions"
$env:TEMP_NOTE_AI_MODEL = "gpt-4.1-mini"
```

Для локальных OpenAI-совместимых серверов можно указать свой адрес API, например:

```text
http://localhost:11434/v1/chat/completions
```

## AI-описание

Кнопка `AI описание` в правой панели пересчитывает краткое описание выбранного файла.

Если описание уже было рассчитано и файл не менялся, приложение берет результат из кэша.

При наведении на файл TempNoteManager также может показать описание во всплывающем предпросмотре.

## AI-тэги и классификация

Кнопка `AI разметка` анализирует выбранные файлы, а если выделения нет - видимые файлы, и сопоставляет их с существующими категориями.

Перед запуском приложение показывает, сколько будет новых AI-запросов, сколько файлов возьмется из кэша и примерную оценку объема. Если включен поиск или фильтры, без выделения AI будет работать только с видимым списком.

Один файл может получить несколько тэгов и цветов, если AI считает, что он подходит к нескольким категориям.

Колонка `Тэги` показывает найденные тэги. Эти тэги помогают быстро понять, куда файл, вероятно, относится.

## AI-подсказки категорий

Кнопка `AI категории` просит AI посмотреть на видимые файлы и предложить недостающие категории.

Сценарий работы:

1. Нажмите `AI категории`.
2. Посмотрите предложенные категории.
3. Отметьте нужные.
4. Нажмите `Создать выбранные`.

TempNoteManager создаст директории категорий в корневой папке категорий и сохранит их описания.

## AI-кэш и стоимость запросов

AI-кэш хранится здесь:

```text
%APPDATA%\TempNoteManager\ai-cache.json
```

Кэш привязан к SHA-256 содержимого файла. Поэтому перемещение или переименование файла не заставляет приложение заново анализировать описание и тэги, если содержимое не изменилось.

Категории версионируются по имени и описанию. Если создать новую категорию или изменить описание существующей, TempNoteManager переанализирует только новую или измененную часть классификации.

Практический совет: сначала создайте несколько понятных категорий с хорошими описаниями, затем запускайте `AI разметка`. Так будет меньше повторных запросов и точнее результат.

## Где хранятся данные

Настройки:

```text
%APPDATA%\TempNoteManager\settings.json
```

AI-кэш:

```text
%APPDATA%\TempNoteManager\ai-cache.json
```

Локальные флаги и журнал:

```text
%APPDATA%\TempNoteManager\file-state.json
%APPDATA%\TempNoteManager\operation-journal.json
%APPDATA%\TempNoteManager\session-backups
```

AI-ключ:

```text
Windows Credential Manager -> Generic Credential -> TempNoteManager.AI.ApiKey
```

Сессия Notepad++:

```text
%APPDATA%\Notepad++\session.xml
```

Backup-папка Notepad++:

```text
%APPDATA%\Notepad++\backup
```

Перед записью изменений в `session.xml` приложение создает `.bak`-копию рядом с файлом. Для отмены операций дополнительно создаются снимки в `%APPDATA%\TempNoteManager\session-backups`.

## Типичный рабочий процесс разбора

1. Закройте Notepad++.
2. Откройте TempNoteManager.
3. Нажмите `Обновить`.
4. Включите `Только временные`, если сначала разбираете временные заметки.
5. Создайте несколько категорий с описаниями.
6. Нажмите `AI категории`, если хотите получить подсказки недостающих категорий.
7. Нажмите `AI разметка` для выбранных или видимых файлов.
8. Просматривайте файлы справа и перетаскивайте их в категории.
9. Для важных временных файлов используйте `Сохранить как...`.
10. Для мусора используйте `Удалить`.
11. Если меняли порядок вкладок, нажмите `Порядок`.
12. Откройте Notepad++ и проверьте результат.

## Частые проблемы

### В списке нет файлов

Откройте `Настройки` и проверьте путь к `session.xml`. Если Notepad++ использует другой профиль или portable-версию, выберите `session.xml` вручную через кнопку `…`.

### AI выключен

Откройте `Настройки`, включите AI, заполните адрес API, модель и AI-ключ, затем нажмите `Сохранить`.

### AI просит создать категории

Для `AI разметка` нужны категории с описаниями. Создайте хотя бы одну категорию в блоке `Категории`.

### Файл не перемещается в категорию

Проверьте, что файл существует на диске и что у приложения есть права записи в папку категории.

### Notepad++ не увидел изменения

Закройте Notepad++ перед записью изменений в `session.xml`. Если Notepad++ был открыт во время операции, он мог перезаписать сессию при закрытии.

### Кириллица в файле отображается странно

TempNoteManager читает текст для предпросмотра безопасным способом, но кодировка старых файлов может быть нестандартной. В таком случае проверьте файл в Notepad++ и при необходимости сохраните его в UTF-8.

## Безопасность

Не публикуйте в issue или скриншотах:

- AI-ключ;
- содержимое личных заметок;
- `settings.json`, если там есть приватные пути;
- `ai-cache.json`, если анализировались приватные файлы.

Для тестов с реальными заметками полезно сначала сделать копию профиля Notepad++ или работать с отдельной тестовой сессией.
